# Simple Calculator in C

A simple command-line calculator built using C programming.

## Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Handles division by zero
- User input based calculations

## Language
- C

## Concepts Used
- Switch statement
- If-else
- User input (scanf)
- Output (printf)
